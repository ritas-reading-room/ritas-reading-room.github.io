# Rita's Reading Room

A phone app for Rita: her library (ratings out of 10, would-read-again), mood/genre/vibe picks,
recommendations shaped by her taste, "Find this Book" links (libraries, legal free downloads,
Indigo/Kobo) and what BookTok is reading.

It's a web app: open the site on a phone and add it to the home screen to install it.
Her library is saved on her phone; use **Back up my library** in My Library now and then.

Live at https://ritas-reading-room.github.io (GitHub Pages, deployed from `main`).
